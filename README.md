Built in HTML, this app for HaloITSM lets anyone interactively build complex SQL with just a few clicks.

🛠️ Query Builder: Features
Schema & Fields: Just pick the columns you want from a table list. Easy peasy.

Automatic Joins: Stop stressing about $\text{INNER JOINs}$! The tool handles them automatically as you select fields from different tables (based on our schema). You can still make Custom Joins if needed.

WHERE Clause Builder: Simple interface to add your filters (e.g., column, operator like $= \text{or} >$, value). It always includes the necessary WHERE [Faults].[fdeleted] = 0 to keep the data clean.

Request Type Filter: Super fast way to filter the Faults table by type with a dropdown/buttons for Incident, Change, Problem, etc.

Aggregate Data: Need summaries? You can select columns for GROUP BY and use functions like COUNT, SUM, AVG, etc., to crunch the numbers.

At the end, just hit Copy to Clipboard to grab the finished query, or Clear Query to start over!
